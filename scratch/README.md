# scratch/

Práce na jedno použití — jednorázové skripty, pokusy, mezivýpočty, exporty, které jsi potřeboval jednou.

## Proč existuje

Všechno musí mít své místo, i věci, které si žádné nezaslouží. Bez téhle složky končí dočasné
soubory v rootu workspace nebo vedle skutečných deliverables, a za šest týdnů už nikdo nepozná,
který soubor byl ten reálný output.

Orientační pravidlo:

| | |
|---|---|
| Vyrobeno **pro tebe**, má publikum | → `outputs/` |
| Pomocník, který to vyrobil | → `scratch/` (nebo `work/` daného projektu) |
| Patří k jednomu projektu | → do složky toho projektu |

## Úklid

Nic tady není posvátné — ale **agent to stejně nikdy nesmaže, aniž by se tě zeptal**, a nikdy
přes `rm`. Věci se přesouvají do koše, odkud je dostaneš zpátky.

Než se cokoliv vyhodí, otázka vždycky zní „proč tohle vzniklo a je to ještě potřeba?" Když se
ukáže, že to má hodnotu, **přesune** se to na pořádné místo, místo aby to šlo pryč.
