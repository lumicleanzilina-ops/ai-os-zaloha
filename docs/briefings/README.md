# briefings/

Sem píše svůj výstup scheduled task `morning-briefing` — jeden soubor na běh,
`YYYY-MM-DD-briefing.md`.

Složka se veze prázdná. Existuje proto, aby měl task kam psát hned od prvního dne, a abys mohl zpětně
dohledat, co ti kterého rána přistálo na stole.

Briefing je **report, ne zpravodajství**: začíná tím, co dnes potřebuje rozhodnutí, ne výčtem všeho,
co se stalo. Kdyby ti ranní brief někdy začal znít jako výpis událostí, řekni to — `SKILL.md` toho
tasku je tvůj a můžeš ho přepsat.
