# Profil uživatele

Tady agent drží, kdo jsi a jak chceš pracovat. Čte to na začátku každé session, ať pracuješ v Claude Code, Codexu nebo jiné appce.

## Obsah

- `user-profile.md`: kdo jsi, role, cíle a pořadí zdrojů příjmu (podle něj agent řadí priority), úroveň znalostí a spolupracovníci (jejich jména agent používá v závěru odpovědi).
- `user-preferences.md`: jazyk, styl komunikace, tvrdá pravidla, podpis e-mailů (jak se agent podepisuje, když píše za tebe) a důvěrné projekty, které se nepovyšují do wiki druhého mozku.
- `user-systems.md`: nástroje a napojené služby, úkolový nástroj, hlavní prohlížeč, se kterým jsi přihlášený do služeb, a mapa repozitářů a účtů (osobní, firemní, klientské: který GitHub či jiný účet, kam se nasazuje).
- `tone-of-voice-<kanál>.md` a `brand-profile.md`: tvůj hlas a vizuál (dovednosti `/tone-of-voice-maker` a `/brand-kit-maker`).

Soubory vznikají v onboardingu. Tajemství (hesla, klíče) sem nikdy nepatří.

## Stav

V nové instalaci začíná prázdné a naplní se při prvním nastavení; při upgradu sem agent zkopíruje profil z paměti agenta.
