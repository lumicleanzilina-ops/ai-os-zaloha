# Fungující klíč není důkaz, že jde o správný účet

## Pravidlo
Než ohlásíš jakékoliv číslo vytažené přes nalezený, zděděný nebo recyklovaný API klíč, zavolej
identity endpoint („kdo jsem") a ověř, že účet sedí na toho, o kom reportuješ.

## Proč
Klíč ze starého archivu se autentizuje bez problémů — jenom proti cizímu účtu. Vrátí dobře
poskládaný, naprosto legitimně vypadající výsledek, často čistou nulu. Nic nespadne. To číslo se jen
týká špatného subjektu.

## Jak to použít
Nejdřív identita, potom data. Ověřený identifikátor účtu napiš do reportu, ať příští čtenář vidí,
z jakého účtu čísla pocházejí.
