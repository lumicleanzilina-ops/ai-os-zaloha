# Než začneš automatizovat prohlížeč, prověř API

## Pravidlo
Než u služby, ke které máš programový přístup, začneš automatizovat klikání v prohlížeči, vypiš si,
co ten přístup ve skutečnosti umí.

## Proč
Automatizace prohlížeče je pomalejší, křehčí (iframy, lazy loading, panely, co se vykreslí prázdné) a
místo dat vrací neustrukturované HTML. Je to poslední možnost, ne první pokus.

## Jak to použít
Pokud je automatizace prohlížeče fakt nutná, řekni to **s důkazem** — „vypsal jsem si dostupné
operace a tahle mezi nimi není" — ne jako dojem. A po dvou zaseknutích za sebou v křehkém UI přestaň
tlačit: místo třetího pokusu nabídni uživateli, že si práci rozdělíte.
