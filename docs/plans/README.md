# plans/

Timestampované plány, výzkumy a reporty z týdenních auditů — jedno místo, kde je dohledatelné, co se
kdy rozhodlo a proč.

## Co sem patří

- Plány ze skillu `/planning`
- Výzkumné rešerše k rozhodnutím
- Reporty z týdenních auditů (scheduled task `weekly-improvement`)

> Záznamy jednotlivých session sem **nepatří** — ty píše `/end-session` do
> [`../session-logs/`](../session-logs/). Ranní briefingy mají taky svoji složku,
> [`../briefings/`](../briefings/).

## Pojmenování

- Plány: `YYYY-MM-DD-nazev-veci.md`
- Týdenní audity: `YYYY-MM-DD-weekly-improvement.md`
- Výzkum: `YYYY-MM-DD-tema-research.md`

## Stav

Prázdné místo pro tvoje vlastní plány. Interní vývojové podklady produktu se do zákaznického kitu nebalí.
