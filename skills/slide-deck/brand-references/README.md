# Sem hoď reference svých prezentací a brandu 👇

Dej sem **5–10 ukázek** toho, jak mají tvoje slajdy vypadat — vyexportuj pár slajdů jako obrázky nebo
PDF, nebo sem hoď celé prezentace, jejichž design se ti líbí (svoje, konkurence, kohokoliv).

Agent je prostuduje a zreprodukuje **tvůj** vizuální jazyk: barvy, fonty, layout, odsazení a celkový
pocit — takže prezentace vylezou v tvém brandu, ne jako generická šablona.

Fungují `.png`, `.jpg`, `.webp` i `.pdf`. Čím reprezentativnější ukázky, tím blíž bude první verze.
Kdykoliv se tvůj styl posune, klidně je vyměň.

> Tyhle soubory zůstávají na tvém počítači. `.gitignore` drží tuhle složku (kromě tohohle README)
> mimo git, takže se tvoje reference nikdy omylem nescommitnou ani nikam nedostanou.
