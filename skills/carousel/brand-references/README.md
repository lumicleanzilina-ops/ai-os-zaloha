# Sem hoď svoje stylové reference 👇

Dej do téhle složky **5–10 referencí**, které ukazují, jak mají tvoje carousely vypadat:

- Carousely nebo posty, jejichž design se ti líbí (tvoje, konkurence, kohokoliv).
- Tvoje existující brandové grafiky — post, slajd, one-pager.
- Screenshoty klidně stačí. Kterýkoliv z formátů `.png`, `.jpg`, `.webp`, `.pdf`.

Pak si prostě řekni o carousel. Tvůj agent si tohle **nastuduje, styl ti popíše zpátky a zreplikuje
ho** — paletu, fonty, rozestupy, náladu — takže carousely vyjdou jako *tvoje* značka, ne jako
generická šablona.

Čím reprezentativnější příklady, tím blíž bude první verze. Kdykoliv se tvůj styl posune, klidně je
vyměň.

> Tyhle obrázky zůstávají u tebe v počítači. `.gitignore` drží všechno v téhle složce (kromě tohohle
> README) mimo git, takže se tvoje reference nikdy omylem necommitnou ani nesdílejí.
