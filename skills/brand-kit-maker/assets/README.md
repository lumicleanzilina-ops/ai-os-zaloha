# Sem hoď svoje brandové podklady 👇

Tady žije tvoje vizuální identita. Dej sem všechno, co máš — čím víc toho bude, tím víc bude
všechno, co agent vyrobí, vypadat jako tvoje značka.

**Seřazeno podle hodnoty:**

1. **Logo** — nejlepší je `.svg` (škáluje se bez rozmazání); `.png` funguje taky. Přidej každou
   verzi, kterou máš: plné logo, jen značku/ikonu, na světlé pozadí, na tmavé pozadí.
2. **Barvy** — poznámku s hex kódy tvojí značky (primární, sekundární, akcentní). Neznáš je?
   Agent je vytáhne z tvého loga nebo manuálu.
3. **Fonty** — buď samotné soubory fontů (`.ttf` / `.otf`), **nebo** agentovi prostě řekni názvy
   (např. *„Inter na text, Space Grotesk na nadpisy"*). Zmiň, jestli jsou z Google Fonts.
4. **Brand manuál / grafický manuál** — jakékoliv PDF, co máš (rozestupy, co se smí a nesmí, tonalita).
5. **Pár reálných grafik** — 3–5 postů, slajdů nebo one-pagerů, které vypadají tak, jak to chceš.

Pak spusť **`/brand-kit-maker`**. Agent si tohle všechno nastuduje a napíše znovupoužitelný
**brand profil** — takže tvoje carousely, prezentace, dashboardy a generované obrázky budou
automaticky vypadat jako *tvoje* značka, ne jako šablona.

> Tvoje podklady zůstávají u tebe v počítači. `.gitignore` drží všechno v téhle složce (kromě
> tohohle README) mimo git — loga, fonty a manuály bývají licencované, takže se nikdy omylem
> necommitnou ani nesdílejí.
