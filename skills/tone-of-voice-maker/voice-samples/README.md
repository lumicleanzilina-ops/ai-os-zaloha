# Sem hoď svoje vlastní texty 👇

Dej do téhle složky **5 kusů svého reálného psaní** (čistý text nebo `.md`; víc nevadí) a pak spusť
**`/tone-of-voice-maker`**. Agent je zanalyzuje a postaví detailní profil toho, *jak píšeš* — aby
všechno, co ti napíše, znělo jako ty, ne jako AI.

## ⚠️ Jediné pravidlo: jedna dávka = jeden kanál

**Dávej sem vždycky jen JEDEN typ textu.** Píšeš všude jinak — LinkedIn post nezní jako e-mail a ten
nezní jako dlouhý článek. Smícháním dostaneš rozmazaný průměr, který nezní jako nikdo.

Postav si proto **samostatný profil hlasu pro každý kanál**:

- **Posty na sítě** (LinkedIn / Instagram / X) — jeden profil
- **E-maily / newslettery** — druhý
- **Články / blog** — třetí

Udělej jednu dávku, spusť `/tone-of-voice-maker`, řekni agentovi, o jaký kanál jde (uloží
`tone-of-voice-<channel>.md`). Pak ukázky vyměň a udělej další kanál.

**Vybírej svoje nejlepší a nejreprezentativnější kusy** — agent napodobí přesně to, co uvidí, i se
všemi vrtochy. 5 skvělých ukázek je lepších než 20 průměrných.

> Tvoje texty zůstávají na tvém počítači. `.gitignore` drží tuhle složku (kromě tohohle README) mimo git.
