# Sem hoď svoje vlastní cenové nabídky 👇

Dej do téhle složky **5–10 svých reálných nabídek** — ty, na které jsi hrdý, v tom formátu, ve kterém
je posíláš (PDF, `.docx` nebo čistý text).

Agent je prostuduje a naučí se **tvoji** strukturu, formulace, cenovou logiku a tón — takže nové
nabídky vylezou jako *tvoje*, ne jako generická šablona. Odkouká, jak balíš varianty, jak obhajuješ
hodnotu, jaké máš podmínky a jak mluvíš.

Čím víc (a čím reprezentativnějších) sem dáš, tím blíž bude první verze. Kdykoliv se ti nabídka
změní, klidně je aktualizuj.

> Tyhle soubory zůstávají na tvém počítači. `.gitignore` drží tuhle složku (kromě tohohle README)
> mimo git, takže se tvoje nabídky nikdy omylem nescommitnou ani nikam nedostanou.
