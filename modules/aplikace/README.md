# Volitelný AI OS Dashboard

## Obsah / Struktura
Dashboard je samostatný druhý ZIP. Po dokončení kitu pokračuj [předávkou](../../docs/PREDANI-DASHBOARDU.md). Agent převezme hotový profil, zjistí počítač/server a nastaví zvolené funkce.

## Stav
V tomto KIT ZIPu je jen rozcestník. Žádný backend, Hermes ani aplikace se kvůli používání kitu neinstalují.
