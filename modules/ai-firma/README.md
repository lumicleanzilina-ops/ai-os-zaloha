# Volitelná AI firma v Dashboardu

## Obsah / Struktura
Role, úkoly a jejich kontrola patří do samostatného AI OS Dashboard ZIPu. Navazuje na osobní kit podle [předávky](../../docs/PREDANI-DASHBOARDU.md). Firma se spouští až na základě uživatelova rozhodnutí.

## Stav
Starší vlastní runtime při upgradu nemaž ani nezapínej vedle nové instance. Tento kit neobsahuje druhou frontu úkolů ani další serverový runtime.
